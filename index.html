Каталог страниц

Папки и HTML-страницы подтягиваются автоматически из репозитория. Названия страниц берутся из тега <title>, названия папок — из файла title.txt внутри папки.

Загружаю структуру репозитория…
Чтобы папка получила красивое название, положи в неё title.txt. Первая строка — название папки, остальные строки — описание. Для страниц используй обычный <title>Название</title>.
